How an institution gets its own

No forking, no theme to maintain, no second place to edit content.

  1. Choose a designOne name in a configuration file dresses all sixteen page types.
  2. Set the coloursA palette and a logo. Everything else follows from design tokens.
  3. Connect your contentThe site reads notices, staff, routines and results from your existing system.
  4. PublishEach institution is deployed separately, carrying only its own design.
